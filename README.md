# SOC ALERT DASHBOARD

A cybersecurity project that detects suspicious login attempts and alerts users using log analysis.

## Features

* Detects failed login attempts
* Tracks suspicious IP addresses
* Displays alerts using Streamlit dashboard
* Simple log monitoring system

## Technologies Used

* Python
* Streamlit
* Log Analysis

## Files

* `dashboard.py` → Dashboard interface
* `detector.py` → Threat detection logic
* `logs.txt` → Sample logs
* `main.py` → Main execution file

## How to Run

```bash
streamlit run dashboard.py
```
